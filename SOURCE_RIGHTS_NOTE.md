# Source / Rights Note

This build includes an optional Internet Archive ingestion adapter for
public-domain and selected permissive Creative Commons movie items.

The adapter is intentionally disabled by default. Operators are responsible
for verifying that each item they redistribute is actually licensed for their
intended use. Internet Archive states that uploader-provided copyright/license
information is not guaranteed.

The adapter does not scrape, bypass access controls, or automate third-party
movie-download websites.
